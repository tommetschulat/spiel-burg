# Burg-Spiel

Ein Browser-Spiel nach einer Idee von Felix.

Gegner greifen deine Burg an. Die Türme schießen von selbst, du tippst Gegner an und sammelst Münzen ein. Aus den zwei Häusern im Burghof kommen je 10 Kämpfer. Wenn sie zusammen 20 Gegner besiegt haben, verschwinden sie und 10 neue kommen heraus. Mit den Münzen kaufst du Upgrades für die Burg.

## Spielen

`index.html` im Browser öffnen. Das Spiel läuft am PC mit der Maus und auf dem Tablet mit dem Finger.

Das ganze Spiel steckt in der einen Datei `index.html`. Es braucht keine Installation.
